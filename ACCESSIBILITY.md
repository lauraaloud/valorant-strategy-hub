# VALORANT Strategy Hub Accessibility

## Overview

I worked on making my VALORANT Strategy Hub accessible and responsive for different users and screen sizes.

## Accessibility Features

- Added visible focus outlines for keyboard navigation.
- Used descriptive alt text for map images and agent portraits.
- Included labels for interactive elements.
- Improved text and button color contrast.
- Used responsive layouts for smaller screens.
- Added reduced-motion support for users who prefer fewer animations.
- Used semantic HTML elements such as headings, sections, buttons, and navigation links.

## Keyboard Navigation

The website supports keyboard navigation using Tab, Shift + Tab, Enter, and Space.

Users can navigate between sections and interact with buttons, dropdown menus, and crosshair features without relying on a mouse.

## Responsive Design

I used mobile-first CSS with media queries at 320px, 650px, 900px, and 1000px.

The navigation, map cards, team compositions, and crosshair layouts adjust for different screen sizes.

## Accessibility Testing

I will use Google PageSpeed Insights to test the website's accessibility on mobile and desktop.

After testing, I will document my accessibility scores and any changes I make to improve the results.
